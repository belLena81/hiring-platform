Keep existing event identities and deletion barriers correct; changing routing or the active envelope requires a scoped contract update with all consumers and fixtures, following the pre-MVP single-shape policy.

Embrace State through closed workflow ADTs and a pure decision function `(state, input, time) => Either[WorkflowError, (nextState, commands)]`. Reuse aggregate `LifecycleProgram` where sequential domain transitions need it; keep saga progress distinct from application status. Persist expected-revision state transitions, consumed-message deduplication and emitted outbox commands in one Mongo transaction. An interpreter owns provider calls, retries, timers, leases/fencing and `Resource` lifetimes. A durable timeout is a persisted deadline checked after restart, not only a sleeping fiber.

Reuse durable embedding/reindexing work first; model forward recovery when old embeddings or irreversible deletion cannot be restored. Add interview scheduling only with a scoped provider contract; the local/fake adapter must support realistic failure/reconciliation tests before a real integration is authorized. Compensation itself needs idempotency, bounded retry and an operator repair state. Do not impose Saga machinery on single-transaction status changes or simple outbox delivery.

Demonstrate no lost acknowledged work, no illegal application transitions and convergent provider reconciliation.
