# Development Milestones

## Hiring Analytics Lakehouse

The current analytics milestone is documented in [Hiring Analytics Lakehouse](specs/hiring-analytics-lakehouse.md). It introduces a local batch-only Bronze/Silver/Gold pipeline and bounded Admin reporting. The next separate milestones are Structured Streaming, search evaluation, and scale work.

Completion requires local source-to-projection evidence, data-quality and retention checks, independent code/security reviews, and final QA. The accepted delayed failed-outbox replay risk prevents a final security PASS for this milestone.
